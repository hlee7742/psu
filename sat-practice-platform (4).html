Build a test

Upload a PDF of your own test — Reading & Writing and Math can be in the same PDF or separate files, either way. Claude automatically detects which questions are which and sorts them into the right section. Each upload reads the actual page images as well as the text, so diagrams, graphs, and tables come through accurately, not just plain text. You'll review and fix everything before it's saved, so nothing goes live unchecked.

Important: PDF upload and answer-key parsing call Claude's API, which only works from this platform's Claude-hosted (published artifact) link — not from the independently-hosted version shared with students. Use the Claude link here in Manage Tests, then switch to (or just tell) students to use the independently-hosted link for taking tests. Both read and write the same shared database, so everything stays in sync either way.

Reading & Writing and Math questions are detected automatically and each gets its own count: the first 27 R&W questions found go to R&W Module 1 and the rest to Module 2; the first 22 Math questions found go to Math Module 1 and the rest to Module 2. Adjust the module dropdown per-question below if anything doesn't land right. Uploading again adds to the current test rather than replacing it.

Review questions

Check each question, fix anything wrong, and confirm its module before saving. Rows outlined in red need attention.

Upload an answer key

Upload a spreadsheet (.xlsx/.csv) or a PDF listing the correct answer for each question, and it'll fill in "Correct answer" for the matching questions below — much faster than clicking through each one. Spreadsheets need three columns in this order: Module, Question #, Answer. Module values should clearly say which subject and module, e.g. "R&W Module 1" or "Math Module 2".

"Get progress as JSON" never touches the network — it works even if "Save test" fails (for example, if you're on the Claude-hosted link, which can't reach the database). Import the file later from the independently-hosted link's Manage Tests tab.

A file download may be blocked here (the Claude-hosted link's sandbox sometimes blocks downloads entirely, separately from the database issue). This box works regardless — click inside it, select all (Ctrl/Cmd+A), copy (Ctrl/Cmd+C), then paste into a new text file and save it with a .json extension.

This runs fresh against the test currently selected in the Results tab (—) and always re-checks answers against the CURRENT answer key, even if it was updated after some students already submitted.
